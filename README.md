✈️ Indian Airlines Data Analysis

📌 Project Overview

This project focuses on analyzing Indian airline flight data using Python, SQL, and Power BI.

The objective is to perform data cleaning, Exploratory Data Analysis (EDA), SQL-based business analysis, and interactive dashboard development to understand airline performance, flight delays, revenue trends, and customer satisfaction.

🎯 Project Objectives

- Analyze airline-wise flight operations.
- Identify revenue and profit trends.
- Analyze flight delays and cancellations.
- Compare airline performance.
- Understand customer satisfaction.
- Identify high-traffic routes and cities.
- Create an interactive Power BI dashboard.

3. SQL Business Analysis (MySQL)

Performed business analysis using SQL queries to answer 10 important business questions:

1. Which airline operates the maximum flights?
2. Which airline generates the highest revenue?
3. Which airline has the highest average delay?
4. Which routes have the most flights?
5. Which airline has the highest profit?
6. What is the overall cancellation rate?
7. Which aircraft model generates the highest revenue?
8. Which city has the highest flight traffic?
9. What is the average customer rating for each airline?
10. Which routes have the highest average delay?

4. Power BI Dashboard

Created an interactive dashboard to visualize airline performance and flight-related insights.
